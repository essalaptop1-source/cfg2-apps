How it works

  • Download the exe and open it — no installation, no admin needed.
  • Click Add bot and pick a Python file with your bot's logic. If the token isn't found in the file, paste it manually.
  • Hit Start — the bot comes online. Use Deploy 24/7 to keep it running with Windows in the background.
  • Edit the code anytime with the built-in editor, watch live logs in the console, or manage servers from the admin panel.
  • Updates are checked automatically — new versions download and apply themselves.
🛡️ Only run bots whose code you trust. The app executes the Python you load into it, so treat bot files like any other program.

Requirements

  • Windows 10 or 11 (64-bit)
  • Python 3.9+ installed (needed to run bots) — the app itself is fully self-contained
  • Discord bot token and the discord.py library installed for your Python
